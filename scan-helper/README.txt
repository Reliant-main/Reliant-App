Reliant Scan Helper - install on a scanning computer (one time, about 3 minutes)

1. Unzip this folder somewhere it will stay (for example Documents\Reliant Scan Helper). Don't delete it later - Chrome runs the helper from this folder.
2. In Chrome, go to  chrome://extensions
3. Turn on "Developer mode" (switch at the top right).
4. Click "Load unpacked" and pick the unzipped folder (the one with manifest.json in it).
5. Click the puzzle-piece icon in Chrome's toolbar and pin "Reliant Scan Helper".
6. Click the Reliant icon, paste this computer's station code, click Connect.
7. Open the CashMonkey scan screen, click the Reliant icon again, click "Use Scan Helper on this site", choose Allow.
8. The panel appears on the right of the CashMonkey screen. Type who's scanning, pick the load, Start shift.

Daily use: scan books into CashMonkey as normal. Stream books and ACCEPT books are added to inventory by themselves
(Religious, Reject and SBYB-gaylord books are not). If a book is in poor condition, press DO NOT ADD
(or F8, or scan the DO NOT ADD card) and it is taken back out. Same book twice in a row is not added twice:
use ADD ANOTHER COPY for a real second copy. Hand-search books: press ADD TO INVENTORY (or F9) after looking them up.
To hide the panel: click × on it, or press Alt+Shift+R. To bring it back: Alt+Shift+R, or click the Reliant icon and "Show panel". Hidden, it still counts scans and F8 / F9 / the cards still work.

Amazon sticker barcodes (ASIN / FNSKU labels): scan them like normal. The helper waits for CashMonkey to look the
code up and uses the book's ISBN from CashMonkey. If CashMonkey has no ISBN for it, scan the ISBN on the book instead.

To see this computer's station code later: click the Reliant icon > "Show this computer's code".
